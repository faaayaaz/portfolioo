# Current design: clear work and responsive interaction

The user rejected both the visual concept and lag of the 3D island. This revision follows that feedback with an editorial, project-first layout: bold typography, restrained color, real content, an interactive SVG analytics preview and direct project selection. A reference URL was requested as an optional preference; no new visual reference was supplied during implementation.

The site now uses native inputs and compact React updates. The full charting library is deferred until explicitly opened. It has no WebGL scene, continuous animation loop, scroll pinning, animated counters or pointer-following cursor. Hover transitions are brief and respect reduced motion. All theme, résumé, project, contact and synthetic-data requirements remain supported.

The previous research checked Bruno Simon's [official 2025 portfolio source](https://github.com/brunosimon/folio-2025), his historical [2019 source](https://github.com/brunosimon/folio-2019), [Brittany Chiang v4](https://github.com/bchiang7/v4), and a historical [Rauno Freiberg portfolio source](https://github.com/raunofreiberg/raunofreiberg.github.io/blob/master/portfolio.html). Those were source/repository reviews. Direct live-site access was denied by the environment's network policy. The historical references were never evidence of 2026 launches, and no new live-site review is claimed here.

The immersive direction inspired by the 2025 reference is now superseded. Its code, assets specific to the world, and runtime dependencies have been removed from the active design. No outside site's code, visual assets or exact layout were copied for this revision.
